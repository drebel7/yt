# Migrena — opracowanie tematyczne

Zbiór trzech raportów o migrenie przygotowanych na podstawie lokalnych transkrypcji filmów YouTube z kanałów health/medical. Raporty różnią się długością i szczegółowością.

## Raporty

- [Krótki](01-short.md) — 1–3 minuty czytania, najważniejsze wnioski i praktyczne punkty.
- [Średni](02-medium.md) — 5–8 minut, mechanizmy, przyczyny, profilaktyka, metody naturalne i leki, z przypisami.
- [Długi](03-long.md) — 10–25 minut, pełny przegląd, jakość dowodów, protokoły, przeciwwskazania i bibliografia.

## Metoda

1. Deterministyczne wyszukiwanie regexem po polskich odmianach rdzenia `migren` (bez LLM) w katalogu `transkrypcje/`.
2. Indeks tematyczny w repo: [INDEX.md](INDEX.md) — 223 pliki i 1402 trafienia; kopia robocza: `transkrypcje/_tematy/migrena.md`.
3. Drugi przebieg po synonimach: `transkrypcje/_tematy/migrena-synonimy.md`.
4. Analiza źródeł i synteza w trzech raportach.
