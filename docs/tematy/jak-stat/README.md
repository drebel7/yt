# JAK-STAT / inhibitory JAK — opracowanie tematyczne

Raporty kliniczne o szlaku JAK-STAT i inhibitorach JAK, ze szczególnym uwzględnieniem WZJG oraz chorób hematologicznych. Mechanizmy opisano jako podparcie decyzji klinicznych.

## Raporty

- [Krótki](01-short.md) — 1–3 minuty, najważniejsze fakty.
- [Średni](02-medium.md) — 5–8 minut, mechanizm, zastosowania, bezpieczeństwo.
- [Długi](03-long.md) — 10–25 minut, pełny przegląd, monitorowanie, przeciwwskazania.

## Źródła

- **IBD/JAK:** Crohn's & Colitis Foundation (wykłady farmakoterapii i trudnego IBD).
- **Hematologia:** VJHemOnc (myelofibrosis, ruxolitinib, momelotinib, pacritinib, fedratinib).
- **Mechanizmy:** wykłady akademickie i materiały edukacyjne.
- **Ograniczenie:** w korpusie brakowało dużych, dedykowanych kanałów reumatologicznych i dermatologicznych; JAK w RZS/AZS opisano jako kontekst, nie jako pełny przegląd.
