# JAK-STAT w reumatologii — opracowanie tematyczne

Raporty o inhibitorach JAK w reumatologii, ze szczególnym uwzględnieniem **upadacitinibu** i bezpieczeństwa. Powstały po przeszukaniu **wszystkich 7338 transkrypcji**, z filtrem relevancji: plik musiał zawierać zarówno markery JAK-STAT/leku JAK, jak i terminy reumatologiczne.

## Raporty

- [Krótki](01-short.md) — 1–3 minuty.
- [Średni](02-medium.md) — 5–8 minut.
- [Długi](03-long.md) — 10–25 minut.

## Najważniejsze ustalenia

- W reumatologii inhibitory JAK są opcją na tym samym poziomie co biologiki po niepowodzeniu methotreksatu, z obowiązkową oceną ryzyka (EULAR 2025).
- **Upadacitinib** to selektywny inhibitor JAK1; w reumatologii zwykle 15 mg/dobę, w wybranych wskazaniach jelitowych/skórnych 30 mg.
- Główne ryzyka: półpasiec, TB, WZW B, zakrzepica, MACE, nowotwory, cytopenie, lipidy, wątroba, ciąża.
- **Pasożyty:** brak rzetelnego wątku; większość trafień „parasitic/parasitinib” to błędy ASR od „upadacitinib”. Jedno źródło wymienia toksoplazmozę jako możliwe zakażenie oportunistyczne.

**Uwaga:** opracowanie edukacyjne, nie porada medyczna.
